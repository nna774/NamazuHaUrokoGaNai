# デバイス詳細画面のデータ鮮度・稼働時間を秒単位まで表示する

## 決めたこと

デバイス詳細画面（`dashboard/app.js` `renderDeviceInfo`）の「データ鮮度」「稼働時間」を、
既存の丸め表記（`fmtAgo`、例: `2時間`）に加えて実秒数を括弧書きで併記する
（例: `2時間(7328秒)遅れ`）。90秒未満は元々秒単位でそのまま表示されるため括弧は付けない。

新関数 `fmtAgoExact` を追加し、詳細画面の該当2行だけをこれに差し替えた。
デバイス一覧テーブル（`renderDevicesTable`、`fmtAgo` 呼び出し箇所）は列幅が厳しいという
既存コメント（app.js:1160-1161）があるため対象外とし、丸め表記のまま維持した。

## なぜ

一覧の丸め表記だけでは「2時間」が実際には1時間30分なのか2時間59分なのか区別できず、
欠測監視やデバッグの際に実際の遅延秒数・稼働秒数を正確に把握したい場面があるとの
ユーザー要望。一覧は既存の列幅制約を尊重し、詳細画面のみ変更する方針にした。

## 次に可能になったこと

デバイス詳細画面で `data-freshness` や `uptime` の実秒数を目視確認できるようになり、
欠測監視のwatchdog通知閾値（`NAMZ_OFFLINE_RENOTIFY_S`等）との突き合わせがしやすくなった。
