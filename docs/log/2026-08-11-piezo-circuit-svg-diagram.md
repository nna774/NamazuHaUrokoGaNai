# ピエゾ実験機: 配線図をASCIIからSVGへ差し替え、軽い入力の電圧も確認

## 何を決めたか

`docs/piezo.md`のASCIIアート配線図を読みにくいという指摘を受け、
`docs/img/piezo-protection-circuit.svg`として図を作成し差し替えた。
あわせて「トン」と軽く叩く程度の入力でも約1.5Vが出ることを確認した。

## なぜ

ASCIIアートの配線図（バイアス抵抗がピエゾ(-)側から分岐しているように見える等）
が分かりにくいと指摘され、信号経路（ピエゾ→Node A→Rs→Node B→GPIO4、
Node AからRbがGNDへ、Node Bから2本のダイオードが3.3V/GNDへ）を左から右へ
追える回路図をSVGで作った。

軽い入力の電圧確認は、「弾く操作を禁止すれば保護回路は不要では」という提案を
検討する過程で行った。軽く叩く程度(約1.5V)は単体ではADCの安全範囲(0〜3.3V)に
収まるが、この時点で無視できない電圧域に達している。加えて、このセンサーは
無人で放置され、本来の目的である地震の揺れの強さは制御できない・据え付け中の
不意な衝撃も避けられないため、「操作を制限すれば保護回路を省略できる」という
判断は採らないことにした([docs/piezo.md §4](../piezo.md#4-ピン選定と最小配線phase0)
に追記)。

## 何が覆ったか

特になし（保護回路必須という既存の結論を補強するデータが増えただけ）。

## 次に何が可能になったか

- 配線図が読みやすくなったので、実際の配線作業をこの図を見ながら進められる。
