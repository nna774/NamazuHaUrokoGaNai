# 2026-08-26 福島県沖M4.5 事後解析

`tools/scan_quakes.py`（[2026-08-28の実装](2026-08-28-scan-quakes-jma-feed.md)）が
気象庁の地震一覧から「投げる価値あり」として拾った候補。ユーザーの指示で確認した。
同日08:33の[茨城県南部M3.4](2026-08-26-ibaraki-nanbu-m3.4-post-hoc-detection.md)より
3時間ほど前に発生した別地震。

## 震源要素

気象庁`list.json`より: 発生 2026-08-26 05:23頃(秒不明) JST、震源 N37.4/E141.8、
深さ30km、M4.5、最大震度2、震央距離269km・震源距離271km。

## 1. 自動検知の有無

`/events?all=1&size=20`を確認したが該当時刻付近に`event_id`は無い。

## 2. detectlab解析

### 標準設定（3軸・1-10Hz）

```
device=1  STA/LTA peak=2.37（閾値に遠く未達）
  P窓 SNR=1.00 直線性=0.58 → 微妙 / S窓 SNR=1.04 直線性=0.49 → 微妙
device=2  STA/LTA peak=2.84（閾値未達）
  P窓 SNR=0.97 直線性=0.51 → 微妙 / S窓 SNR=0.94 直線性=0.59 → 微妙
```

両機とも閾値に届かず、P窓・S窓のSNRもほぼ1（[図](img/2026-08-26-fukushima-oki-m4.5-8min.png)）。

### 低帯域(0.5-2Hz)・水平2軸

```
device=1  STA/LTA peak=3.90（僅差で閾値未達）
device=2  STA/LTA peak=6.20（閾値を明確に超過、onset 05:24:38.5・S窓終了の21秒後・直線性0.93）
```

device2のピークは[図](img/2026-08-26-fukushima-oki-m4.5-lowband-xy.png)でも記録全体で
最も高く孤立しており、S窓のすぐ後（コーダ域）というタイミングも実体波の減衰として不自然ではない。
ただし**device1は同時刻に対応する山を作っておらず**（僅差で閾値未達なだけで、他のprobable判定例
で見られる「2台同時に立つ」形にはなっていない）、直線性の一致度パネルもこの時刻だけが
突出しているようには見えない。

### 追記: 直線性の一致度を20秒binで定量確認（ユーザー指摘を受けて）

上のdevice2単独ピーク（t+280〜291s、S窓終了の10〜21秒後）は、ユーザーから
「どっちもS波のwindowの後に跳ねてる気がする」と指摘を受けて`--corr-bin 20`で
2機の直線性相関を区間別に数値化した。結果、**その単独ピークの時間帯(t=[280,300)s)は
相関がむしろ背景以下**（frac=0.13, mean_corr=-0.24。背景frac=0.19, mean_corr=+0.03）で、
device2固有のノイズだったと判断できる。

一方、**S窓終了(t=+77s)の直後〜コーダ域(t=80〜180s)に、2機の直線性相関が背景を上回る
区間が2つ見つかった**:

```
t=[ 80,100)s  frac(corr>=0.6)=0.45  mean_corr=+0.26
t=[140,160)s  frac(corr>=0.6)=0.52  mean_corr=+0.46
（背景 t=-150〜-30s: frac=0.19  mean_corr=+0.03。全区間中の最大背景binはt=[-160,-140)のfrac=0.38）
```

この2区間は他のどの背景binよりも高く、S波到達直後という物理的に妥当な位置にある
（[岩手県沖M4.9の前例](2026-08-09-iwateoki-m4.9-post-hoc-detection.md)と同様、
実体波からコーダへの減衰でP/S直後にエネルギーが残る形と整合）。ただし
frac=0.45/0.52は突出はしているが劇的な差ではなく（背景最大0.38との差は一応ある）、
かつt=100〜140sは一旦0.23〜0.31まで下がっており連続した山ではない。

## 判定

**微妙寄りの弱いprobable。** 単発のSTA/LTAピーク（device2のみ、S窓直後）自体は
device2固有のノイズだったが、**S窓直後の2機直線性相関の定量確認で、背景の最大値を
上回る区間が物理的に妥当な位置（コーダ域）に見つかった**。ただし山が2つに割れている・
差が劇的ではない、という理由で確信は持ちきれず、[2026-08-20茨城県沖M3.5](2026-08-20-ibaraki-oki-m3.5-post-hoc-detection.md)
と同程度の「弱いprobable、検出限界の境界線上」とする。
