# 2026-08-19 補強検知の代替センサ候補を追加検討（雑談ベース・未着手）

`other-sensors.md`のピエゾ実装は着手済みで進行中([docs/piezo.md](../piezo.md))。
その次のネタとして、雑談の中で以下を検討した。

## 経緯

GY-530(ToF距離センサ)を「揺れを測れるか」と聞かれたところから始まった:

1. **ToF距離センサ単体**は不採用と判断。センサと壁が同じ建物内の2点なので
   地震動でほぼ剛体的に一緒に動き、相対距離の差分が出にくい（加速度計・ピエゾが
   慣性系に対する動きを直接拾うのとは根本的に違う）。
2. 「錘を吊ってそこへの距離を測る」という改良案が出て、これは**機械式地震計
   （質量-バネ系）の再発明**だと気づいた——バネで浮いた錘は慣性で遅れるので、
   フレームとの相対変位は本物の地震動を反映する。ただしこれは
   [geophone.md](../geophone.md)で検討済みの質量-バネ系と同じ機械設計
   （固有周波数f0をターゲット帯域より下げ、制動比を臨界制動に追い込む）を
   要求する。センサを良いものに替えても、ボトルネックが機械設計側に移るだけ。
3. SW-58010P（スプリング式振動スイッチ）も検討したが、機械式スイッチで
   感度調整不可・波形も取れず、既存表の「傾斜/ボール/水銀スイッチ」枠と
   同じ評価（△）に帰着すると判断。ピエゾに劣る。
4. 上記2を踏まえ、質量-バネ系からの連続値ピックアップ方式として
   **光てこ・磁気ピックアップ(ホール素子)・オプティカルフローセンサ**の
   3案を出した。「たらい(水盆)式」も話に出たが機構が難しく見送り。

## 決定・記録した内容

`other-sensors.md`に新設した §3.1/§3.2 に記録:

- 3案はいずれもgeophoneと同じ質量-バネ系が前提で、違いはピックアップ方式のみ
- **光てこ**: レーザー+鏡の反射で角度変化を光路長ぶん幾何学的に増幅。機械精度中、
  デバッグ性は高い（目で見える）が光学アライメントの手間がある
- **磁気ピックアップ**: 錘に磁石、フレーム側にホールIC。コイル巻き不要で
  三者中もっとも機械工作が楽。磁石があるので渦電流制動が副産物的に手に入る
- **オプティカルフロー**: ドローン/マウス用チップを錘に取り付ける。
  **フレーム固定のまま床を見る使い方は不可**——ToF距離センサと同じ理由で
  差分が出ない。錘側に取り付けて初めて意味を持つ、という注意点を明記した
- 部品の見繕い: 磁気はSS49E(入門)→MLX90393(方向情報が要る場合)、
  オプティカルフローは取り付け距離次第でPMW3901/PAA5100JE(数cm〜)か
  PMW3360/ADNS-9800系マウスチップ(数mm接写)
