# 2026-11-03 千葉県北東部M4.7(14:40)の事後解析

直近約40日の「投げる価値あり」圏内の地震を`scan_quakes.py`で洗い、`/events?all=1`と突き合わせて
対応イベントが無かったものを`detectlab`で確認した（5件）。**捕れていたのはこの1件だけ**で、
他の4件は完全埋没（末尾）。

震央N35.7/E140.6・深さ50km・M4.7・最大震度3。震源距離216km。同震源域のM4.8(10/8)・M5.4(10/29 00:07)・
M4.4(10/29 03:32)に続く4件目。

## 1. 自動検知の有無

無し。`/events?all=1`に該当時刻のevent_idは無かった。標準設定のSTA/LTAがdevice1で3.87と閾値4に
わずかに届かず、device2は4.91で超過したが確定条件は満たさなかった。

## 2. detectlab解析

分丸めの14:40:00基準だと窓が実際の到達より約15秒早く、P窓SNR1.00・「微妙」になった。
低帯域のonset候補のP・Sの到達時刻差(14:40:49と14:41:14、差約25秒)が216kmのS-P時間と合うので、
そこから逆算して推定発生**14:40:15**で撮り直した(`--eew-estimated`)。

標準設定(1-10Hz, xyz):

| 2 | 4.91(超過) | 1.38/0.47 要検討 | 2.82/0.78 **地震らしい** | 2.24/0.75 **地震らしい** |

両機とも14:40:49(P)と14:41:13〜14:41:22(S)にonset候補が揃い、後者は直線性0.84〜0.93。
機間相関(20秒bin、背景frac0.16/mean+0.00、低帯域は背景0.24/+0.06): 標準設定で推定発生+40-120秒に

+120〜140秒で背景へ戻る。M4.4(223km)は到達後約80秒で終わっていたのに対し、M4.7は約100秒続く。

計測震度は両機とも保存区間で I=0.4（震度0）。気象庁の最大震度3は震源近傍で、216km離れた
この観測点では震度0相当になる。

## 3. 判定

**probable detection(good)。** 標準設定でもdevice2が閾値超過し、S窓・コーダ想定域が両機とも地震らしい。
低帯域では両機が明確に閾値を超え、onset時刻の一致・機間相関・直線性が揃う。

## 4. 保存

`promote_event.py --onset "2026-11-03 14:40:50" --pre 180 --post 600`で両機を手動昇格し、`relate`と
`verdict good`を付けた(`0001-59789481`/`0002-59789481`)。揺れは推定発生+140秒前後で終わっており、
保存区間の終端(14:50:50)までにコーダ取りこぼしの懸念は無い。新規発行直後の操作なので
CloudFront invalidationは打っていない。
