# 2026-09-28 UPSバッテリー電圧ADC設計へのレビュー指摘を反映した

## 何をしたか

前日実装したUPSバッテリー電圧ADC計測(未配線・設計段階、
[log/2026-09-27-ups-battery-adc-design.md](2026-09-27-ups-battery-adc-design.md))に
第三者から3点の指摘を受け、回路定数を見直した。実機はまだ組んでいないので、
配線図・firmwareのコメント・docsのみの修正(config.hの定数は変わらない)。

## 指摘と対応

1. **ソースインピーダンスが高い**: 旧構成はR1‖R2=50kΩで、ESP32 ADCの推奨上限
   (概ね10kΩ以下)を大きく超えていた。R1/R2を100kΩ+100kΩ→10kΩ+10kΩへ下げ、
   分圧比(2:1)は維持。漏れ電流は18µA→183µAへ10倍増えるが、ESP32本体の消費電流
   (数十〜数百mA)と比べれば誤差レベルなので気にしないと判断した。
2. **GPIOへの保護素子が無い**: 分圧中点とADCピンの間に直列保護抵抗Rs(1kΩ)を追加。
   ついでにC1(0.1µF)の位置を分圧中点からADCピン直前へ移動し、Rs×C1=100µsの
   RCフィルタとしても働かせる形にした(①の緩和にも寄与)。DC定常状態ではRsに
   電流が流れないため分圧比自体は変わらない。
3. **ADC個体差・非線形性**: 既に`analogReadMilliVolts()`(Arduino-ESP32コア内蔵の
   eFuse Vref/Two Point較正込みAPI)を使っており、生の`analogRead()`+理論値では
   なかった。指摘のうち「eFuse較正を使う」は対応済みと確認。「最終的には実測補正
   が要る」は元々docs/ups.md §5に書いてあった計画のままで、追加対応は無し。

## 次に何が可能になったか

回路定数が固まったので、実機で分圧回路を組む時はこの値(10kΩ+10kΩ+Rs1kΩ+C1
0.1µF)通りに部品を用意すればよい。較正手順自体は変わらない。
