# ピエゾ実験機: GPIO4への実接続後、phase0を改めて達成した

## 何を決めたか

[前回撤回した測定](2026-08-11-piezo-gpio4-not-connected.md)（GPIO4未接続の
誤測定）をやり直し、GPIO4へ実接続した状態で反応を確認できた。**phase0を
改めて達成とする。** [docs/piezo.md §4/§5](../piezo.md)を更新した。

## なぜ

実接続後のログ（`min,max,pp`）で、無入力時のベースラインはpp~110〜150程度と
フローティング時(220〜240)より低く安定した。突いた瞬間の窓ではppが
1000〜2000超まで跳ね、その後2〜3窓かけて減衰しながらベースラインへ戻る
パターンが繰り返し観測できた。例:

```
0,1302,1302
312,967,655
232,364,132   ← ベースライン復帰
```

このパターンを信頼できると判断した理由:

- **突く強さに応じて反応の大きさが変化する**（弱い接触でpp~300程度、強めに
  突くとpp~1800〜2400）。単なる「触れた/触れてない」の二値ではなく、強度に
  応じた反応に見える。
- **衝撃直後に跳ね、複数窓かけて減衰する**という時間パターンが、静電ノイズの
  単発グリッチではなく、機械的な振動が収まっていく物理現象として自然。
- 強く突くとmin=0（D2のクランプ範囲）まで振れる場面もあり、保護回路が
  設計通り機能していることも合わせて確認できた。

## 何が覆ったか

- [前回の撤回](2026-08-11-piezo-gpio4-not-connected.md)で未達成に戻していた
  phase0を、実接続後の再検証で改めて達成に戻した。

## 次に何が可能になったか

- センサ・保護回路・マイコンの組み合わせが実際に機能することを確認できたので、
  次はカンチレバー固定方法とおもりの選定という機械設計に進める
  （[docs/piezo.md §5](../piezo.md#5-次にやること)）。
