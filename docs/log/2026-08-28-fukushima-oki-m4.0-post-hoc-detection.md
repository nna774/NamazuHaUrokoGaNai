# 2026-08-28 福島県沖M4.0 事後解析

ユーザーから[tenki.jpの地震詳細ページ](https://earthquake.tenki.jp/bousai/earthquake/detail/2026/08/28/2026-08-28-04-46-09.html)を提示され「これって捕れてる? 微妙だと思う」と聞かれたので、
[docs/post_hoc_detection.md](../post_hoc_detection.md)の標準手順で確認した。

## 震源要素

- 発生時刻: 2026-08-28 04:46頃(秒不明) JST、気象庁発表04:49
- 震源: 福島県沖 N37.0/E141.2、深さ約60km
- M4.0、最大震度2（田村市・楢葉町・川内村・大熊町。関東の震度データなし）
- 津波の心配なし

観測点(湯沢町)からの震央距離212km・震源距離220km（`detectlab.py --eew`が自動算出）。

## 1. 自動検知の有無

`/events?all=1&size=20`を確認したが、該当時刻付近に`event_id`は無い
（直近は2026-08-27 04:23の三陸沖M6.1）。リアルタイム閾値未達で正式イベントは立たず。

## 2. detectlab解析

### 標準設定（3軸・1-10Hz）

```
device=1  raw_rms=0.1788gal bp_rms=0.0719gal  STA/LTA peak=1.88
  P窓 SNR=0.94 直線性=0.45 → 微妙
  S窓 SNR=1.09 直線性=0.44 → 微妙
device=2  raw_rms=0.1322gal bp_rms=0.0534gal  STA/LTA peak=2.00
  P窓 SNR=0.98 直線性=0.62 → 微妙
  S窓 SNR=1.13 直線性=0.45 → 微妙
```

閾値(4)に遠く届かず、P窓・S窓とも背景と分離できない。
（[図](img/2026-08-28-fukushima-oki-m4.0-8min.png)）

### 低帯域(0.5-2Hz)・水平2軸

```
device=1  STA/LTA peak=3.80  P窓 SNR=1.05 直線性=0.61 → 微妙 / S窓 SNR=1.30 直線性=0.50 → 要検討
device=2  STA/LTA peak=3.76  P窓 SNR=1.17 直線性=0.57 → 微妙 / S窓 SNR=1.56 直線性=0.65 → 地震らしい
```

両機ともSTA/LTA peakが閾値4に肉薄（3.76/3.80）し、device2のS窓は単独では「地震らしい」判定が出た。
ただし[図](img/2026-08-28-fukushima-oki-m4.0-lowband-xy.png)を見ると、STA/LTA・直線性とも
P窓・S窓周辺だけが際立っているわけではなく、記録全体（前後10分）にわたって同程度の
山と直線性の一致（相関パネルの緑帯）が繰り返し出ている。過去のprobable detection例
（[2026-08-08 茨城県北部M3.8](2026-08-08-ibaraki-m3.8-post-hoc-detection.md)や
[2026-08-24 浦河沖M6.0](2026-08-24-urakawa-oki-m6.0-post-hoc-detection.md)）で見えた
「到達窓だけベースラインから明確に跳ねる」コントラストが無い。

## 判定

**微妙／要検討。** P/S到達窓の数値だけ見れば低帯域で閾値近傍まで来ているが、
同じ強さの山が到達前後にも継続して出ており、地震由来と背景ノイズを区別できる根拠が弱い。
M4.0・震源距離220kmは、過去記録にある同程度の福島県沖M4.0（深さ50km・震央268km、
`docs/noise.md`既存エントリ、probable判定）よりやや近いはずだが、今回は判定を上げる
材料が揃わなかった。ユーザーの「微妙だと思う」という直感と一致する結果。

正式イベントには該当しない（`/events`に無し）ため、`promote_event.py`での手動保存は
見送った。probable detectionと呼べる根拠が無く、90日以内に再解析したくなるほどの
確度でもないため。
