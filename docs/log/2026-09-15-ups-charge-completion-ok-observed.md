# 2026-09-15 UPS充電完了(OK点灯)を初めて観測

[2026-09-14の放電試験](2026-09-14-ups-discharge-test.md)の続き。放電試験後、空近く
(無負荷2.35〜2.36V)からUSBを再接続して充電を再開したサイクルの結果。

## 分かったこと

1. **CR→OKへの切り替わりを初めて観測した**。19:03時点で3.37Vまで上昇し以降は
   ほぼ横ばいだったところ、翌日12:28に確認するとOKが点灯し充電が停止、その時の
   電圧は3.38Vだった
2. **ただし切り替わった正確な瞬間の電圧・時刻は不明**——寝ている間に起きたため、
   19:03(3.37V)〜12:28(3.38V)の17時間強のどこかとしか言えない。12:28に見た3.38Vは
   切り替わり直後の値ではなく、**切り替わってから充電も負荷も無い状態でしばらく
   休んだ後の、リラクゼーションで落ち着いた値**である可能性が高い（[2026-09-14のログ](2026-09-14-ups-discharge-test.md)
   で確立した「充電直後の電圧は表面電荷の影響で真のOCVより高く出る」現象と同種）。
   切り替わった瞬間の電圧はこれより高かった可能性がある
3. **前回(2026-09-10〜11)CRのまま3.59Vで4時間動かなかった件との整合性**: 3.38V
   (今回・完了)が3.59V(前回・未完了)より低く、一見矛盾するように見えるが矛盾しない
   と考えられる。前回のセッションは無瞬断切替の確認やIC再起動の切り分けで**充電中に
   何度もUSBを抜き差ししており**、完了判定を電流の積算やタイマーで行うタイプの
   安価な充電ICであれば、電源断のたびにその積算がリセットされ、電圧がいくら
   頭打ちに見えても永遠に「完了」と判定されない可能性がある。つまり前回の3.59Vは
   そもそも一度も完了判定に到達していない「まだ充電中の踊り場」であり、今回
   初めて中断無しで最後まで走らせて完了に到達した、という理解が筋が通る
4. **OK→CRの切り替わりも動的であることを確認した**。OK点灯中に負荷を一瞬繋ぐと
   （電圧がわずかに沈む）即座にCRへ戻った。これは電源再投入で再評価される
   （2026-09-11に確認済み）のと同種で、ICが状態を固定表示しているのではなく
   継続的に監視・再評価していることの追加の裏付けになる

## 更新される結論

- **§4「OKに切り替わらないのでは」という前回時点の暫定的な懸念は撤回する**。
  中断無しで放置すれば切り替わることを確認した
- 完了時の電圧は**電圧の絶対値そのものではなく、充電プロセスが中断無く完了したか
  どうかに依存する**可能性が高く、「終止電圧は何V」という単純な1値では語れない
  かもしれない。次に測る機会があれば、切り替わりの瞬間に立ち会って（長時間
  連続で見張るか、通知手段を用意するか）本当の切り替わり電圧を捕まえたい
