# docsの陳腐化を横断チェックして直した

## 何が起きたか

`docs/STATUS.md`のデバイス一覧にdevice 3(ピエゾ実験機)が抜けていたのをきっかけに、
他のdocsにも同種の「実装が進んだのに記述が追いついていない」箇所がないか横断調査した。

## 見つけたもの・直したもの

1. **`docs/STATUS.md`残タスク末尾**: 「ADXL355 2号機のセンサ検証・設置（進行中）」が
   完了後も残っていた。同ファイルのデバイス一覧テーブルでは既に「実運用機」扱いなのに
   矛盾していた。削除し、「済んだ主な機能」節へ移した。
2. **`docs/STATUS.md`冒頭の日付ヘッダ**: 「2026-08-04時点」のまま10日分の進捗
   （OTA・欠測監視・退役mute・ピエゾ実験機phase1等）が反映されていなかった。
   日付とタイトルを更新した。
3. **`docs/other-sensors.md`**: 「雑談ベース・未着手」のままだったが、実際はこの構想が
   具体化して`docs/piezo.md`に引き継がれ、phase1（クラウド統合）まで完了している。
   冒頭に引き継ぎ済みの旨を追記した。
4. **`docs/device_overlay.md`**: ファイル内で矛盾していた。冒頭の「進捗」欄と
   「着手順（未決）」節は「bが最後になりそう」「a/b/cどれも未着手」と書いていたが、
   末尾の「ダッシュボードでの利用（実装済み・2026-08-09）」節では**bを先に実装済み**と
   書かれていた。当初の予想と実際の順序が逆転したことが分かるよう冒頭・着手順節を書き直した。
5. **`docs/design.md`・`docs/wire_format.md`**: sensor_type帯域(`128〜249`)を
   「未実装、設計のみ」としていたが、ピエゾ実験機(device_id=3)で実装済み・稼働中。
   該当箇所の文言とdesign.md→wire_format.mdのアンカーリンク（見出し変更に伴い変わった）を
   直した。
6. **`CLAUDE.md`のドキュメント歩き方の表**: other-sensors.md・piezo.mdの行のステータス
   表記が同様に古かったので更新。`docs/piezo.md`自身のH1見出し「（着手・進行中）」も
   「（phase1完了・稼働中）」に変えた。

## 対応

上記6箇所をまとめて修正。実装・設計そのものの変更は無し、ドキュメントの記述を
現状に合わせただけ。
