# 【予想・未検証】追加コンデンサが周波数選択フィルタではなく容量分圧器として効いている可能性

`docs/log/2026-08-14-piezo-buzzer-lowpass-design.md`でZ軸(圧電ブザー素子)の
ローパス(C=200nF)の効果を実データで確認した際、理論値(1次RC、50Hzで
-9.4dB≒振幅1/3)よりも実測の改善幅(数十〜百倍)が遥かに大きかった。クランプ
飽和の解消で説明を付けたが、**別の見落としがあった可能性に気付いた**ので、
検証はしていない予想として記録する。

## 見落とし: Node A(ピエゾ側)は「電圧が固定された理想電源」ではない

当初の`fc = 1/(2π×Rs×C2)`という計算は、Node A(ピエゾ+Rbのノード)の電圧が
下流の負荷に関わらず一定という前提（Node Aを理想電圧源とみなす近似）に
立っていた。しかしピエゾ素子は電圧源ではなく、**それ自体が小さな
静電容量C1(仮定20nF、未実測)を持つ電荷源**——出力インピーダンスが高く、
電圧源としては弱い。

そこにC1の10倍(C2=200nF)ものコンデンサを下流に足すと、電荷はC1とC2で
単純に分配される。この「容量分圧」は**周波数に関係なく効く**。

## 導出（電荷源モデル）

ピエゾを電流源i(t)、Node Aの対地容量C1(+Rb、50Hzでは無視可能)、Rsを挟んで
Node Bに追加コンデンサC2、とするKCLから:

```
V_B/V_oc = 1 / [ (1 + C2/C1) - jωRsC2 ]
```

（V_oc = ピエゾを無負荷(開放)にした時に出る電圧、i(t)/(jωC1)で定義）

k = C2/C1 = 200nF/20nF(仮定) = 10として、DC〜低周波極限:

```
|V_B/V_oc|(ω→0) = 1/(1+k) = 1/11 ≈ -20.8dB
```

50Hzで計算し直しても|V_B/V_oc|≈1/11.4（DC比で追加-0.3dB程度）——**1-10Hz帯
(≈1/11.0)と50Hz(≈1/11.4)でほとんど差が無い**。つまり、**当初「50Hzだけ選択的に
削れる」と思っていたフィルタは、実際には信号帯域も共振も一律に約11倍
(-20.8dB)減衰させているだけで、周波数選択性はほぼ効いていない**、というのが
この計算の帰結。

## 状況証拠

無風の静穏時（クランプ飽和が絡まない条件）のベースラインを比べると:

- フィルタ前(§4実測、無風室内): pp~110〜260
- フィルタ後(今回実測): pp~10台

クランプ解消では説明できないこの差は、容量分圧仮説とよく整合する
（クランプ飽和の解消だけなら、そもそも飽和していなかった静穏時のpp自体は
大きく変わらないはず）。

## 含意（未確認・要検証）

1. **Z軸の地震動(1-10Hz)への感度も、共振ノイズと同程度(≈1/11)落ちている
   可能性が高い**。§9設計時の「1-10Hz帯を削らない」という目標は、実際には
   達成できていないかもしれない
2. **LDT0-028K側(§9冒頭、まだ未実装)も同じ穴を抱えている、しかもより深刻**。
   LDT0-028KはC1=480pF(データシート記載の確定値)に対し設計中のC2=27nFは
   k=56.25——容量分圧だけで**-35dB(約57分の1)**という、Z軸よりさらに大きい
   一律減衰になる計算
3. Z軸側はC1が未実測の仮定値(20nF)なので、分圧比の正確さにも同じだけ不確実性
   が乗る。LDT0-028K側はC1がデータシート既知値なので、この仮説を検証・
   再設計しやすいのはむしろLDT0-028K側

## LDT0-028K側の対応案（未決定、検討のみ）

1. **C2をC1(480pF)と同程度〜数倍に抑える**: k=2〜5程度(C2=1〜2.4nF)なら
   分圧損失を-9.5dB〜-15.6dB程度に圧縮できる。ただしfc=1/(2π×220kΩ×1nF)
   ≈723Hzとなり、**周波数選択性はほぼ捨てることになる**（「50Hzだけ削る」
   という当初の設計目的は放棄し、「クランプ回避のための一律減衰器」に
   設計意図を書き換える必要がある）
2. **C2をC1未満に保ったまま既存Rs=220kΩで20〜30Hzのカットオフを狙う**:
   計算上133MΩ級の抵抗が必要になり非現実的（Rbと同格の値、配線・リーク
   電流・入手性の面で厳しい）
3. **バッファ(単電源op-amp、ボルテージフォロワ)を1段追加**: 低インピーダンス化
   してから当初想定通りの素直な1次ローパスを組む、教科書的に正しい解。
   部品と数十円のコストが増える

現時点では方針未決定。1が部品追加ゼロで最も筋が通るが、「フィルタ」ではなく
「一律減衰器」だと設計意図を書き換えた上で、減衰後もLDT0-028Kのデータシート
感度(mass別50〜800mV/g)で1-10Hz帯の実信号がADC分解能に対して十分な余裕を
残せるか、という検算に置き換える必要がある。
