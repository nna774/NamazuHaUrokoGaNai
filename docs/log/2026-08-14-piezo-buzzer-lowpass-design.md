# 既存Z軸（圧電ブザー素子）側のアンチエイリアシングローパスを設計した

`docs/log/2026-08-13-ldt0-028k-lowpass-filter-design.md`でLDT0-028K用保護回路
（Rs=220kΩ）側のアンチエイリアスRCローパスは値まで決定済みだったが、これは
X/Y軸に新規導入するLDT0-028K向けの設計で、**既存Z軸（GPIO4の圧電ブザー素子、
Rs=47kΩ）側のローパスはまだ手つかずだった**（`docs/piezo.md` §7末尾に
「風除け筐体・アナログローパスの設計はまだ未着手」と明記されていた）。

ユーザーから「Z軸の圧電素子にも共振を落とすためのローパスをつけたい、
LDT0-028Kのほうでは考えていたがこっちでもできるか」と聞かれ、既存の設計方針
（LDT0-028K側の§9）をそのままZ軸にも適用できると確認した。

## LDT0-028Kとの違い: 共振周波数が既知

LDT0-028K側の設計は、実機到着前で共振周波数が未実測だったため「1-10Hz帯を
削らない下限」と「ナイキスト(50Hz)より十分低い上限」の2つの制約から
20〜30Hzへ絞る手探りの設計だった。

Z軸（ブザー素子）は`docs/piezo.md` §5で共振周波数を**49.947Hz**とオシロ実測
済みなので、同じ考え方をより直接的に適用できる——共振がナイキストのほぼ真下に
あることも既に判明している。

## 設計: 既存Rsをそのまま流用

LDT0-028K側と同じ手法。新しい抵抗は追加せず、Node B（Rs=47kΩの直後、
クランプダイオードD1/D2と同じノード）からGNDへコンデンサ1個を足すだけの
1次RCローパスにする。

```
fc = 1 / (2π × 47kΩ × 220nF) ≈ 15.39Hz
```

カットオフの狙いどころ(10Hz/15Hz/20Hz)をユーザーに確認し、**15Hz付近
(C≈220nF、E6系列)** を採用と決定した。1-10Hz帯をほぼ削らず、共振(≈50Hz)を
十分に落とすバランスとして選んだ。

## 既知の限界

1次RCローパスは-20dB/decadeしか効かない。fc=15.39Hzに対し50Hzでの減衰量は
`f/fc ≈ 3.25`より概算約10dB(振幅で約1/3程度)に留まる——共振を消し去るほど
急峻ではない。LDT0-028K側の設計（mass=1でも-10.8dB程度）と同程度の限界を
持つ。対策の主軸は`docs/piezo.md` §7が既に決めている「風防(励起源を減らす)」
で、このローパスは補助という位置づけ——これもLDT0-028K側の結論と同じ。
