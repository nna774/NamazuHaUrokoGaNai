# 既存Z軸（圧電ブザー素子）側のアンチエイリアシングローパスを設計した

`docs/log/2026-08-13-ldt0-028k-lowpass-filter-design.md`でLDT0-028K用保護回路
（Rs=220kΩ）側のアンチエイリアスRCローパスは値まで決定済みだったが、これは
X/Y軸に新規導入するLDT0-028K向けの設計で、**既存Z軸（GPIO4の圧電ブザー素子、
Rs=47kΩ）側のローパスはまだ手つかずだった**（`docs/piezo.md` §7末尾に
「風除け筐体・アナログローパスの設計はまだ未着手」と明記されていた）。

ユーザーから「Z軸の圧電素子にも共振を落とすためのローパスをつけたい、
LDT0-028Kのほうでは考えていたがこっちでもできるか」と聞かれ、既存の設計方針
（LDT0-028K側の§9）をそのままZ軸にも適用できると確認した。

## LDT0-028Kとの違い: 共振周波数が既知

LDT0-028K側の設計は、実機到着前で共振周波数が未実測だったため「1-10Hz帯を
削らない下限」と「ナイキスト(50Hz)より十分低い上限」の2つの制約から
20〜30Hzへ絞る手探りの設計だった。

Z軸（ブザー素子）は`docs/piezo.md` §5で共振周波数を**49.947Hz**とオシロ実測
済みなので、同じ考え方をより直接的に適用できる——共振がナイキストのほぼ真下に
あることも既に判明している。

## 設計: 既存Rsをそのまま流用

LDT0-028K側と同じ手法。新しい抵抗は追加せず、Node B（Rs=47kΩの直後、
クランプダイオードD1/D2と同じノード）からGNDへコンデンサ1個を足すだけの
1次RCローパスにする。

```
fc = 1 / (2π × 47kΩ × 220nF) ≈ 15.39Hz
```

カットオフの狙いどころ(10Hz/15Hz/20Hz)をユーザーに確認し、**15Hz付近
(C≈220nF、E6系列)** を採用と決定した。1-10Hz帯をほぼ削らず、共振(≈50Hz)を
十分に落とすバランスとして選んだ。

## 既知の限界

1次RCローパスは-20dB/decadeしか効かない。fc=15.39Hzに対し50Hzでの減衰量は
`f/fc ≈ 3.25`より概算約10dB(振幅で約1/3程度)に留まる——共振を消し去るほど
急峻ではない。LDT0-028K側の設計（mass=1でも-10.8dB程度）と同程度の限界を
持つ。対策の主軸は`docs/piezo.md` §7が既に決めている「風防(励起源を減らす)」
で、このローパスは補助という位置づけ——これもLDT0-028K側の結論と同じ。

## 追記: 実装はC=200nF(100nF×2並列)で行った

設計直後にPR #109をマージしたが、実際に手元の抵抗・コンデンサ詰め合わせを
確認したところ**220nF(224刻印)は入っておらず、100nFまでしか無かった**。
100nFを2個持っていたため、Node B-GND間に2個並列でC=200nFとして実装した。

- コンデンサをNode Bへ並列に追加しても、D1/D2(クランプダイオード)とは
  通常時(0〜3.3V)は非導通で干渉せず、接合容量もpFオーダーで200nFに対し
  無視できるため問題無いことを確認した。
- 200nFでの再計算: `fc = 1/(2π×47kΩ×200nF) ≈ 16.93Hz`。220nF狙いの
  15.39Hzとほぼ差が無く(50Hzでの減衰も約9.4dB、220nF案の10.2dBとほぼ同等)、
  実用上の違いは無いと判断しそのまま採用した。
- **Node B-GND間への実装(はんだ付け)は完了。動作確認(Serial出力での
  ベースライン確認)はまだ**——`docs/piezo.md` §6のTODOに残した。

## 追記2: 実データでの動作確認と、カンチレバー付け直しとの切り分け実験

実装(23:19起動)直後からdashboardが明らかに静穏化したが、同じ作業の中で
**カンチレバーが脱落し付け直す**という出来事も起きていたため、静穏化が
ローパスの効果なのかカンチレバー付け直しの効果なのか切り分けが必要になった
（ファーム側はorigin/masterへ書き直したが、`PiezoSensor.h`のADC読み取り自体は
初回実装から無変更、`piezo_config.h`/`piezo_main.cpp`の差分もOTA・可観測性
ヘッダの追加のみでサンプリング関連の定数変更は無いことを確認し、ファームは
容疑から除外した）。

保護回路がブレッドボード実装のため、追加した100nF×2のコンデンサだけを
一時的に抜き差しできた。カンチレバーの状態を固定したまま、API `/recent`
エンドポイントで前後を比較した:

1. **コンデンサ有り(23:19起動直後)**: 平均pp/バケット≈7.6、レンジ≈252、
   クランプ無し
2. **コンデンサ抜き(23:30、カンチレバーは同一のまま)**: 平均pp/バケット≈435、
   レンジ≈2053(実装前の参考値≈2000〜2066とほぼ一致)、クランプ復活
   (6000バケット中487)
3. **コンデンサ挿し戻し後**: 直近1分の生データでstdev≈10.1、レンジ37.3、
   クランプ無し——静穏な状態に完全に復帰

カンチレバーを固定したままコンデンサの有無だけを変えて静穏⇄騒がしいが
再現したため、**静穏化の主要因はローパスコンデンサそのものと確認できた**。

理論上の1次RC減衰(50Hzで約-9.4dB、振幅で約1/3)よりも実測の改善幅(数十〜
百倍オーダー)が遥かに大きい点については、フィルタ前は風等の励振で頻繁に
ADCがクランプ(0付近)へ張り付く飽和状態だったためと推定した——50Hz成分が
クランプ閾値を下回るところまで削れたことで飽和自体が解消し、線形なdB計算
だけでは説明できない非線形な改善が上乗せされたと考えられる。
