# 2026-11-13 ライブ画面の縦軸既定を±100galから自動に変更

## 決定

ライブタブの縦軸(`#yrange`)の既定値を `±100 gal` から `自動` に変えた。タイトルクリックの
全リセットも自動に戻す。イベント詳細側(`#event-yrange`)は元から自動が既定。

## 理由・覆ったこと

±100固定は「平常時は直線、逸脱＝異常として読める」という意図で選んでいたが、
ユーザー要望で自動を既定にした。平常時のノイズ形状が見える方を優先した形。固定レンジで
異常を読みたい時はURL `r=100` か操作子で切り替えられる。既存の共有URLは `r=` を
持っているので表示は変わらない。
