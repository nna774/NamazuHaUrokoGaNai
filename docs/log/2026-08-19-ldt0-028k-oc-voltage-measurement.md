# LDT0-028K、分圧プローブを自作して開放電圧を安全に実測した

注文していたLDT0-028K（[docs/log/2026-08-12-piezo-phase1-impl.md](2026-08-12-piezo-phase1-impl.md)で
導入検討していたTE Connectivity製PVDFフィルム振動センサ）が届いた。§4「教訓」で踏んだ
ブザー素子の時と同じく、ESP32へ接続する前にオシロで開放電圧を実測する手順を踏んだ。

## 手元のオシロが50Vpk上限だった問題

データシートの想定最大値（90°曲げで>70V）に対し、手元のQuimat 2.4インチデジタル
オシロスコープは**最大入力電圧50Vpk**（仕様: 入力インピーダンス1MΩ、帯域0〜200KHz、
感度5mV/Div〜20V/Div、12bit）だと判明。直結すると壊れるリスクがあるため、分圧プローブを
自作して測定範囲を拡張する方針にした。

## 分圧プローブの設計

```
ピエゾ(+) ──R1── ノードA ──R2── ピエゾ(-)
                    │                │
              オシロ探針(信号)   オシロGND(グラウンドクリップ)
```

ピエゾ(-)・R2下端・オシロGNDクリップは全部同じ1点（この測定回路内だけの基準点。
大地アースの意味ではない）にまとめる。

**設計上の注意点（オシロの入力インピーダンス1MΩがR2と並列に効く）**: 分圧比は単純な
`R2/(R1+R2)`ではなく、`R2_actual = R2 ∥ Zscope`を使った`N = (R1+R2_actual)/R2_actual`で
計算する必要がある。R2がZscope(1MΩ)と同程度だと無視できないズレが出る。

抵抗の手持ちを確認したところ**10MΩの単品が既にあった**ため、これをR1にそのまま採用した:

- **R1=10MΩ(単品1本)・R2=1MΩ(1本)、計2本**
- `R2_actual = 1MΩ ∥ 1MΩ = 0.5MΩ`
- `N = (10M+0.5M)/0.5M = 21倍`

安全マージン: 想定70V→スコープ入力3.3V。想定外込みで3倍(210V)出ても10V。50Vpk上限まで
大きな余裕がある。当初は前回のブザー素子Rb実装(1MΩ×10直列)を踏襲して「R1=9MΩ(1MΩ×9直列)・
R2=1MΩ、N=19倍」を検討したが、10MΩ単品の在庫が見つかったことで**抵抗2本だけで組める上に
マージンも同等以上**という、より簡単な構成に落ち着いた。

## 実測結果: Vpp=3.00V（換算63V）、データシート想定内

指で何度か曲げて試したところ、オシロ画面上のVpp最大値は**3.00V**（2V/div、HOLD=単発
トリガでの捕捉、AC結合）で頭打ちだった。

**実際の開放電圧: 3.00V × 21 = 63Vpp**

データシートの想定最大値(90°曲げで>70V)に近いが、それを超えてはいない——ブザー素子の
時のような「想定を裏切られる高電圧」は今回は無かった。正規品でデータシートがある分、
汎用ブザー素子より予測が効いたと言える。分圧回路自体もスコープ画面上は3Vしか振れず
50Vpk上限には遠く及ばず、安全に測定できた。

**この結果により、既存の保護回路設計（Rs=220kΩ、70V想定で計算済み。
[docs/log/2026-08-12-piezo-phase1-impl.md](2026-08-12-piezo-phase1-impl.md#rs直列抵抗保護用)参照）が
そのまま使えると確認できた。**

## 次にできるようになったこと

保護回路（Rb=500MΩ or 430MΩ単体、Rs=220kΩ、D1/D2=1N60）を実際に組む段階へ進める。
固有振動数の実測・mass量を振っての感度実測はまだ未着手。
