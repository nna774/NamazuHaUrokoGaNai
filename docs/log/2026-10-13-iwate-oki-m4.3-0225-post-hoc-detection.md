## 1. 自動検知の有無

## 2. detectlab解析

標準設定（3軸・1-10Hz）:

```
python tools/detectlab.py --at "2026-10-13 02:25:00" \
  --eew "39.5,142.6,20,2026-10-13 02:25" --minutes 10 --device 1 2 --intensity \
  --out docs/log/img/iwate-oki-m4.3-1013-0225-8min.png
```

## 3. 判定

**完全埋没（critical）**。震源距離436kmは目安レンジ(139〜278km)の外側で、想定どおり。device2低帯域の閾値超過は到達窓の外の孤立ピーク。

新しい知見は無いため`docs/noise.md`への追記は行わない。

onset候補の時刻は`detectlab`が出す`t+`（データ開始からの経過）ではなく、発生時刻（分単位に丸められた気象庁値）からの経過秒に換算して書いた。
