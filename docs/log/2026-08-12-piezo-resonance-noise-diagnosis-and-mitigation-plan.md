# ピエゾ実験機、共振ノイズをナイキストの観点で捉え直し対策方針を決めた

[log/2026-08-12-piezo-wind-sensitivity-observation.md](2026-08-12-piezo-wind-sensitivity-observation.md)
でFFTにより「風がむき出しのカンチレバーを直接励振している」と確証した件を、
別の会話筋で**サンプリング理論の観点**から捉え直した。風対策そのものの結論
（本体を風から遮る方向が筋）は変えないが、**次期センサ(LDT0-028K)のmass選定**
と**アンチエイリアス対策の優先順位**に直接影響する発見があったので記録する。

## `piezo_config.h`のコメントの誤り（実害は無し）

```
// 固有周波数は実測約50Hz(docs/piezo.md §5)。ナイキストに余裕を持たせ
// 本線と同じ100Hzにする。
```

この一文は誤り。`kSampleRateHz=100Hz`のナイキスト周波数は50Hzで、共振
(実測約50Hz)とちょうど重なっており余裕は無い。§5の「1-10Hz帯（震度算出の
対象帯域）から5〜10倍以上離れている」という正しい計算と、ナイキストからの
距離という**別の軸**を実装時に混同していた。設計ドキュメント側にはナイキストへの
言及自体が無く、`piezo_config.h`のこのコメント1箇所だけの問題。

実害は無いと判断した。地震動そのもの(1-10Hz)はfs=100Hzに対し十分な余裕(5倍)
があり正しく標本化できている。共振はそもそも測りたい信号ではなく校正無し・
タイミング一致だけを見る設計（[other-sensors.md](../other-sensors.md)）なので、
共振の周波数が畳み込みで何Hzに化けようと「バーストが記録されたか」という
判定自体は損なわれない。

## リスク: 風由来ノイズがエイリアシングで信号帯そのものに混入しうる

厄介なのは「見た目が汚い」ことではなく、共振がエイリアシングで1-10Hz帯に
畳み込まれると**記録された1-10Hz帯の値自体に風由来のノイズが不可逆に
混入する**点。振幅ベースのタイミング一致検知だけなら実害は薄いが、将来
「本当に低周波の揺れか」を選別するフィルタを足そうとした時には手遅れになる。

新規発注したLDT0-028K（mass別共振表は
[log/2026-08-12-piezo-phase1-impl.md](2026-08-12-piezo-phase1-impl.md#ldt0-028kte-connectivity製pvdfフィルム振動センサを導入する時の注意)
参照）でも同じ問題が起きる。fs=100Hzで畳み込むと:

| mass | 共振周波数 | 畳み込み後 | 1-10Hz帯との関係 |
|---|---|---|---|
| 0（未装着） | 180Hz | 20Hz | 帯域外 |
| 1（0.26g） | 90Hz | **10Hz** | **帯域内（上端に直撃）** |
| 2（0.52g） | 60Hz | 40Hz | 帯域外 |
| 3（0.78g） | 40Hz | 40Hz（畳み込み無し） | 帯域外 |

以前は「mass=1か2あたりから試す方がバランスが良さそう」（感度とアナログ
安全マージンの軸だけで判断）としていたが、ナイキストの軸を入れるとmass=1は
最悪の相性と分かった。感度の軸とナイキストの軸は独立で、片方が良くても
もう片方が悪くなりうる。

## 対策を2軸に整理し、優先順位を決めた

- **軸1: 励起源そのものを減らす（風防）**。既存の風観測ログの結論
  「本体を風から遮る」と同じ方向。LDT0-028K到着後、ユニバーサル基板ごと
  箱に収める案が有効（crimped contactsで基板固定できる設計のため）。現状の
  割り箸固定ではこれ以上の防風は難しく、今すぐ着手はできない。
- **軸2: 残った共振を除去可能な状態にする（アンチエイリアス）**。3案を検討:
  - **2a. fsを上げる（200Hz級）**: 却下。送信・バッファのコストが増える。
  - **2b. ADC手前にアナログRCローパスを追加**: fsに依存せず効く。今の保護回路
    (Rs/Rb)は直流カットのハイパスで役割が違い、ローパスは別途必要。
  - **2c. 本線と同じ手法（1kHz読み取り→ボックスカー10点平均→100Hzに間引く、
    [design.md](../design.md)「サンプリングとオーバーサンプリング」）を転用**:
    送信・バッファのコストが増えない利点があるが、周波数応答を計算すると
    `|H(f)| = (1/M)|sin(πfM/fs)/sin(πf/fs)|`（M=10, fs=1000Hz）は
    50Hzで64%・60Hzで51%・90Hzで11%しか減衰せず、零点は100Hzの整数倍にしか
    無いsinc型。本線が助かったのは元のノイズが広帯域(白色ノイズ的)で
    RMSベースの平均化(√10≈3.2倍)が効いたためで、**LDT0-028Kの共振のような
    狭帯域の単一ピークには効果が薄い**（特にmass=2の60Hzはほぼ素通し）。

**主軸は軸1(風防)+軸2b(アナログRCローパス)に決めた。** 軸2cは送信コストが
増えない利点があるため実装だけはして実測で効果を確認する対象として残すが、
主軸としては採用しない。

## 次に可能になったこと

- LDT0-028K到着後、風防箱の設計とcrimped contacts基板固定を進める（軸1）
- ADC手前のアンチエイリアスRC定数を計算する（軸2b、目標カットオフは
  1-10Hz帯を削らずできるだけ低く、例えば20〜30Hz程度が候補）
- 余力があれば2cも実装し、2bとの実測比較で「送信コスト無しでどこまで効くか」
  を検証する
