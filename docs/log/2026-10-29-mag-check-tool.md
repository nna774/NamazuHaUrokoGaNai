# 2026-10-29 MLX90393の固定オフセット・ドリフトを見る`tools/mag_check.py`

方位センサ検討（issue #250の手法3）で、手元のMLX90393を使えるか確かめる道具。
既存の机上確認スケッチ`firmware/src/mlx90393_main.cpp`（`pio run -e mlx90393-bringup[-c3] -t upload`）が
出す`t_ms,status,x_uT,y_uT,z_uT,temp_C`を読み、(a)回した時の円/球の中心＝固定オフセット
（ハードアイアン）と半径、(b)静置時の中央値の時間変化(µT/時)を出す。`firmware`側は変更していない。

## 余りの個体は磁化済み

手元に余っているMLX90393は、[2026-08-27のログ](2026-08-27-sensor-pickup-bringup-firmware.md)で
**鉄ピンに磁石を2cmまで近づけて磁化させた、まさにその個体**（ピンが抜けなかったもの）。
その時の静置ベースラインは、磁石を近づける前が`x≈2.3,y≈14.7,z≈-49µT`(ノルム51µT=地磁気そのもの)、
磁化直後が`x≈-42,y≈-34,z≈-86µT`(ノルム約102µT)、数分後`x≈-48.9,y≈-38.4,z≈-76.8µT`(ノルム約99µT)。
固定オフセットは概算で70µT台に達し、水平地磁気(約30µT)を上回る。

2か月経った今回の実測を上と比べれば、**鉄ピンの残留磁化が自然に戻るか**を実データで確認できる。
基準値は上の数字。ノルムが51µTに近づいていれば減衰、約100µTのままなら固定。

## 見方

- 回す: 水平な机でセンサをゆっくり1〜2周。半径は水平地磁気(約30µT)、中心が固定オフセット。
  3軸とも40µT以上振れる回し方なら球フィットになり、半径は全磁力(約45〜50µT)に相当する。
- 置く: 動かさず数十分以上。中央値のトレンド(µT/時)が磁化の安定性。
- 「オフセット/半径」が0.3未満なら補正で十分、1.0を超えるなら固定の磁化が支配的で、
  ピンを切る・消磁・別個体を検討する（issue #250）。

テストは`tools/tests/test_mag_check.py`（合成データでフィット・網羅度・ドリフトを検証）。

## 追記: C3の配線をGPIO3/4に寄せられるようにした

GPIO5/6は3.3V・GND(基板の反対側の辺)から遠く配線が長くなるため、同じ辺にあるGPIO3/4で使えるようにした
（ESP32-C3のI2Cは任意のGPIOに割り当てられる。避けるのはストラップのGPIO2・BOOTのGPIO9）。
`mlx90393_main.cpp`のピン番号を`-DMLX90393_SDA_PIN`/`-DMLX90393_SCL_PIN`で上書きできるようにし、
`[env:mlx90393-bringup-c3-gpio34]`（SDA=GPIO3、SCL=GPIO4）を足した。既定(5/6)は変えていない。
この作業用Mac(arm64・Rosettaなし)では公式`espressif32@7.0.1`のままだとビルドできない
(`toolchain-riscv32-esp`(8.4.0+2021r2)がx86_64版のみで`Bad CPU type in executable`。xtensa側はarm64ネイティブ)。
そのため`[env:mlx90393-bringup-c3-gpio34]`だけは`platform`をpioarduino版(55.03.311、arm64ネイティブのC3 toolchain)に
明示pinした。`pio run -e mlx90393-bringup-c3-gpio34`はSUCCESS(Flash 33.1%)で、コンパイルコマンドに
`-DMLX90393_SDA_PIN=3 -DMLX90393_SCL_PIN=4`が入っていることも確認した。既存の`mlx90393-bringup-c3`は公式pinのまま。
実機への書き込み・動作(status=0x00)は未確認。

注意: pioarduino版でビルドすると、追跡対象の`firmware/certs/amazon_root_ca1.pem.piobkp`が消える
（`board_build.embed_txtfiles`の処理の副作用とみられる）。`git checkout -- firmware/certs/`で戻すこと。

## 実測(C3 SuperMini＋余りのMLX90393、同じブレッドボード上、床に置いて測定)

SDA=GPIO3・SCL=GPIO4で書き込み、`status=0x00`で通信確認。ブレッドボードごと水平に1周回して逆回しで1周戻した
（[図](img/mag-check-rotation-floor.png)）。

| 条件 | 中央値 x,y,z [µT] | ノルム |
|---|---|---|
| 机の上(PC・スピーカー近傍、静置) | -15.0, +61.5, -43.2 | 77 |
| 床の上(静置、コンパスを横に置いた状態) | +2.4, +25.2, -26.4 | 36.6 |

- 回転60秒(230サンプル): XY円フィットの**中心(固定オフセット) = (-19.3, +26.2)µT、大きさ32.5µT、半径21.2µT**、
  残差RMS 0.57µT(2.7%)、周回の網羅100%。円は非常にきれい(ソフトアイアンの歪みは小さい)。
  Zの振れは3.4µTで水平に回せている。オフセット/半径=1.53。原点が円の外にあるので、補正前の
  `atan2(y,x)`では方位を出せないが、中心を引けば出せる。
- 机の上の高い値(ノルム77µT)は、ピンの磁化よりも机まわりの影響が大きかった。8/27に磁化直後の約100µTから、
  床の上の静置は36.6µTまで下がっており、ピン由来の固定オフセットは少なくとも減っている（1点なので暫定）。
- 半径21.2µTは水平成分の目安(約30µT)より小さい。室内の減衰か、ライブラリの換算係数か、場所の差かは未切り分け。
  方位(向き)はXYの感度が等しければ影響されない（円の残差が小さいので概ね等方）。

### コンパスとの突き合わせ（手法2と3の相互検算）

床での静置姿勢を写真に撮り、横に置いたコンパス(針は離しても向きが変わらず)と比べた:
- 静置値からオフセットを引くと (x,y)−中心 = (+21.7, −1.0)µT。**水平の地磁気は+x軸の向きで、
  +xから時計回りに約3°**(大きさ21.7µTは円の半径21.2µTと一致)。
- 写真では、基板のシルク印字の+xが画像上で約116°(時計回り、上=0°)、コンパスの緑の針(北端)が約113°。
  **+x軸は磁北とほぼ同じ向き**で、磁気センサの補正後の向きとコンパスの読みは数度の誤差(写真の読み取り精度)で一致した。
- つまり、**このセンサの+x軸は磁北を向く配置で、磁気センサ(手法3)を回転補正すれば絶対方位が出せる**ことと、
  針を信用して磁針(手法2)でも同じ値が出ることが、同じ姿勢の1点で確認できた。
- 偏角(磁北と真北の差、関東〜新潟で約8°西偏、要確認)は定数補正。

### 回転の中身（2周ずつ）

取り込み中の累積回転は-2.00周(t=42秒で折り返し)から逆回しで戻った。1周は中央値約23秒。往路(162サンプル)と
復路(69サンプル)を別々にフィットしても、中心は(-19.3,+26.2)/(-19.0,+26.1)、半径は21.3/21.1で、
ずれは中心0.3µT・半径0.2µT以内。往復で結果が変わらず、ケーブルのねじれや手の位置による偏りは小さい。

### ドリフト確認(30分静置)

回転測定の後、ボードを床に動かさず置いて30分(6885サンプル)取った。
- 中央値 x=-2.85, y=+30.00, z=-24.93µT。標準偏差は0.23/0.23/0.33µT。**トレンドは x=-0.27, y=-0.19, z=+0.09µT/時で、
  30分の総変化は x=-0.13, y=-0.09, z=+0.04µT**。センサの1LSB(約0.15µT刻み)程度で、有意なドリフトは見えない。
- 回転測定のオフセット(-19.3,+26.2)で補正した水平方位は、標準偏差0.79°、**1分中央値で-0.50〜+0.49°(ピーク間1.0°)**。
  トレンドは-0.4°/時でノイズ内。1µTの変動は約2.7°に相当する(半径21.2µTに対して)。
- 温度はこの区間で18.7〜19.9℃(1.1℃)しか動かず、回帰(x=+0.14,y=+0.11µT/℃)は参考値。回転測定中は約26℃まで上がっていた
  ので、温度による変化は、温度を大きく振った別の測定で確かめる必要がある。
- 解析の不具合を直した: 取り込み開始前の残り1点が先頭に混ざり、静置データが「動いた」と誤判定され、継続時間も欠測の7分ぶん
  伸びていた。`mag_check.py`が欠測(5秒超)で区間を分けて最長区間を使い、動きの判定を1〜99パーセンタイルにした。
- 「土台のずれ」の検知閾値の目安: この条件の方位ノイズはピーク間約1°なので、2〜3°を超える変化はずれとして扱える。
  ただし30分・室温ほぼ一定の条件で、数日・季節・設置場所での安定性は別。

### WiFiを動かした時の影響（`mlx90393_wifitest_main.cpp`、`tools/mag_wifi_effect.py`）

本線のESP32と同居させる前に、WiFiの電流がセンサ出力を動かすかを測った。資格情報なしで、WiFi OFFの窓(20秒)と
「WiFi STA＋非同期スキャン連続・送信出力19.5dBm」の窓(20秒)を交互に繰り返し(440秒、11組)、センサは
ESP32から約10cmのブレッドボード上。各スキャン窓の中央値から前後のOFF窓の平均を引いた(直線的なドリフトが相殺される)。

| 軸 | 差(スキャン−OFF) [µT] | 窓内標準偏差 OFF / スキャン |
|---|---|---|
| x | -0.014 ± 0.020 | 0.222 / 0.214 |
| y | +0.048 ± 0.011 | 0.208 / 0.219 |
| z | -0.045 ± 0.029 | 0.317 / 0.307 |

- **有意な差は無い**(最大0.05µT、量子化0.15µT以下)。標準偏差の比は0.96〜1.05で、WiFiで荒れてもいない。
  水平の差ベクトル0.05µTは、最悪でも方位0.13°に相当する(半径21.2µT)。サンプル間隔も変わらない(中央値261ms)。
- 限界: スキャンは送受信の電流が出る状態だが、本線の「接続してTLSでバッチを送る」負荷そのものではない。
  USB給電のデスクトップ条件で、センサまで約10cm。実機の電源経路・配線・設置位置で変わりうる。
  接続して実際に送る負荷での確認は資格情報が要るため未実施。

## 分かったこと・まだ分からないこと

分かった(この机上の条件で):
- MLX90393は、回転補正すれば水平地磁気の向きを数度の精度で測れる。円は非常にきれい(残差2.7%)で、
  補正後の向きがコンパスの針と数度で一致した。余りのピン磁化個体でも、固定オフセットを引けば使える。
- 机の上の高い値はピンではなく周囲の影響が大きい。ピンのオフセットは8/27の磁化直後より減っている(暫定)。

まだ分からない(設置場所は別条件の可能性がある):
- 固定オフセットが再給電・移動・数日の単位で動かないか(30分静置では動かなかった)。「土台のずれの検知」に使う前提で、
  数日後の再測定、設置場所への持ち出し、温度を大きく振った測定で確かめる。
- 設置場所(device1/2のESP32・UPS・電源線の近く)での円の中心と歪み。周囲の鉄・電流が増えれば中心は動き、
  歪み(ソフトアイアン)も出うる。実機の置き場所で同じ回転を取り直す。WiFi送信中の影響は、スキャン条件では見えなかった(上記)。
- 磁気センサの軸と、device1/2の加速度センサの軸の対応(取り付けの平行度)。磁北に対するセンサの向きは
  出せても、地震計の軸が磁北から何度かは、この対応が要る。
- 偏角(磁北と真北、約8°西偏、要確認)の定数補正と、水平半径が目安(約30µT)より小さい理由(換算係数・室内減衰)。
