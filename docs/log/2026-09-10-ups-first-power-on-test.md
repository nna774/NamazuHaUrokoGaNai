# 2026-09-10 UPSセット初回通電試験

発注していたLiFePO4 UPSセット(LFUPSMA互換モジュール + オーム電機LS-BLFP18A-S)が届き、
初めて通電した記録。`docs/ups.md`§4・§5の未解決事項のうち何が埋まったかが本題。

## 分かったこと

1. **バッテリー+USB接続で出力5.1V確認**。基板シルクの「電池を繋がないと出力が一切出ない」
   仕様通り、両方繋いだ状態での基本動作は正常
2. **無瞬断切替を確認した**。出力5V系に仮設置したLED(電流確認用)が、USB(AC側)の抜き差しで
   点灯状態・明るさとも変化せず——切替時の瞬断は目視レベルでは無い
3. **§4の主要な未解決事項が1つ解けた**: USB給電が切れると充放電IC自体が電源を失い、CRを
   含めLEDが両方消灯することを確認した。これで「両方消灯＝AC給電断（バッテリー駆動中）」を
   3値信号として使える見込みが立った。実測した状態遷移は以下の3通り:
   - バッテリーあり・USBあり(充電中) → CR点灯
   - バッテリーあり・USBなし → 両方消灯
   - バッテリーなし・USBあり → 一度OK点灯を見た記憶があるが再現せず。基板上のコンデンサに
     残った電荷による過渡現象の疑い。実運用ではバッテリーが常時接続されている前提なので
     この組み合わせ自体が想定運用に出てこず、優先度を上げて深追いしなかった
4. **充電時の電圧推移をログした**（バッテリー到着直後3.34V起点）:

   | 時刻 | 電圧 |
   |---|---|
   | 17:12 | 3.39V |
   | 17:27 | 3.394V |
   | 17:43 | 3.413V |
   | 18:11 | 3.426V |
   | 18:38 | 3.431V |
   | 19:03 | 3.46V |
   | 20:45 | 3.57V |
   | 21:45 | 3.59V |
   | 22:39 | 3.59V |
   | 22:46 | 3.59V |
   | 23:41 | 3.59V |
   | 01:47(翌9/11) | 3.59V |

   21:45〜01:47の4時間、3.59Vからほぼ動かずCR点灯も継続——単なる踊り場ではなく
   **頭打ちに達したと見てよい状態**まで確認できた。§5で想定していた終止電圧
   3.6〜3.65Vより低い**3.59V付近が実際の頭打ちライン**という見立てが有力になった。
   CR→OKへの切り替わりは今回のセッション終了時点でも確認できず、持ち越し
5. **測定に使ったDMM(HIOKI 3244-60)のDC電圧確度は±0.7%rdg±4dgt**。3.4V付近の読みだと
   誤差幅は概ね±28mV——今回ログした区間ごとの数mV〜十数mVの増減はほぼ測定誤差の範囲内
   だったと判断し、以後は**±0.03V(30mV)未満の差は「変化なし」扱い**とする方針にした
   （短時間の細かい上下より、数十分〜1時間スパンでの傾向を見る）

## 次にやること

- CR→OKへの切り替わりは今回のセッション(17:12〜翌01:47)では最後まで確認できなかった。
  次に見る時、切り替わっていればその電圧を実測終止電圧として§5を確定させる
- 切り替わっていなければ、このモジュール個体の終止電圧が3.59V付近である可能性を前提に
  §5の記述を見直す
- 残っている未解決事項（device2の実消費電流未実測、CR/OKのプルアップ電圧レール・
  オープンドレインかどうか）は今回のセッションでは着手していない
