`tools/scan_quakes.py`の候補スキャンより:

- 発生: 2026-09-14 20:00頃
- マグニチュード: M4.3
- 最大震度: 2
- 震源距離: 259km（レンジ154〜307km。境界帯）

## 自動検知の有無

`/events?all=1&size=20`を確認。該当時刻付近の`event_id`なし。閾値未達により正式イベントは立っていない。

## detectlab解析

### 標準設定（1-10Hz・xyz・重ね合わせ）

```
python tools/detectlab.py --at "2026-09-14 20:00:00" --eew "37.5,141.6,50,2026-09-14 20:00" \
  --minutes 10 --device 1 2 --intensity --out docs/log/img/2026-09-14-fukushima-oki-m4.3-2000-8min.png
```

| 窓 | device1 (SNR/直線性) | device2 (SNR/直線性) |
|---|---|---|
| P窓 | 1.02/0.51 微妙 | 0.98/0.48 微妙 |
| S窓 | 1.13/0.31 微妙 | 1.19/0.40 微妙 |
| コーダ想定域 | 1.04/0.46 微妙 | 1.08/0.54 微妙 |

STA/LTA peak 2.09/2.40（閾値4未達）。S窓〜コーダ域の機間相関binは背景水準(frac0.14)からの明確な超過なし。

### 低帯域xy設定（0.5-2Hz）

```
python tools/detectlab.py --at "2026-09-14 20:00:00" --eew "37.5,141.6,50,2026-09-14 20:00" \
  --minutes 10 --device 1 2 --intensity --band 0.5 2 --axes xy \
  --out docs/log/img/2026-09-14-fukushima-oki-m4.3-2000-lowband-xy.png
```

STA/LTA peak 3.90/3.75（閾値4未達、僅差）。S窓（20:00:57-20:01:13）で**両機とも**「地震らしい」判定
（device1 SNR=1.63/直線性=0.61、device2 SNR=2.30/直線性=0.81）。対応する機間相関binも
t=[60,80)s frac=0.36→t=[80,100)s frac=0.45（mean_corr +0.26/+0.31）と、背景水準(frac0.20)を
明確に上回って2bin連続で継続。P窓・コーダ想定域は微妙〜要検討どまり。

## 判定

**微妙（warning）。** STA/LTAは標準・低帯域とも閾値未達で完全な検出とは言えないが、低帯域xyの
S窓〜コーダ前半で両機のSNR/直線性が同時に「地震らしい」水準まで上がり、機間相関も同じ時間帯で
背景の約2倍まで明確に上昇している——単独機のノイズでは説明しにくい一致。震源距離259kmは
レンジ表の境界帯であり、想定通り「捕れるか捕れないかの際」の実例。
