# 2026-09-14 UPSセット放電試験

[2026-09-10の初回通電試験](2026-09-10-ups-first-power-on-test.md)の続き。充電完了後、
バッテリーをモジュールから外した状態で3日ほど家を離れており、その状態から放電試験を行った。

## 分かったこと

1. **充電直後の電圧は真の満充電OCVより高く出ている（リラクゼーション/表面電荷の影響）**。
   前回セッション終了時点(2026-09-11 01:47)で3.59V・CR点灯のまま4時間横ばいだったが、
   バッテリーを3日間モジュールから外して放置していたところ、試験開始前に測ったら
   3.5V程度まで下がっていた（正確な値は測り忘れ）。3日でこの下がり幅は自己放電
   （LiFePO4は月2〜3%程度で小さい）では説明しづらく、充電直後の端子電圧が内部の
   濃度分極で一時的に高く出ていたものが、無負荷で休ませたことで解消したと考えられる。
   **今後「満充電判定」をする時は、充電直後ではなく数時間〜半日休ませてから読む方が
   真のSOCに近い**という教訓が得られた
2. **放電負荷は220Ω×8本並列(合成27.5Ω、出力5V時で約182mA) + 330Ω+LED**で組んだ。
   1本あたり0.114W(定格1/4Wの46%)で、体感は「触ると温かいが即離すほどではない」
   程度——想定通り安全圏だった
3. **電圧推移**（B+/B-、負荷開始13:16）:

   | 時刻 | 電圧 |
   |---|---|
   | 13:16 | 3.41V（3.5V付近からの負荷サグ） |
   | 13:24 | 3.28V |
   | 15:05 | 3.25V |
   | 16:55 | 3.21V |
   | 18:21 | 2.58V（ここから急落開始） |
   | 18:21台のうち | 2.58V→2.48Vまで数分で急落 |
   | 直後 | 2.21V付近で出力LEDが急に暗くなり、B+/B-は2.22V付近まで回復 |

   3.2V付近までの平坦域から2.5V台で急落するカーブは、LiFePO4の典型的な放電末期の
   非線形挙動と一致する
4. **§5で想定していた「2.5V付近でモジュール側保護が効いて止まる」は外れた**。実際に
   起きたのは、**出力電圧が1.8Vまで低下した**こと——これはバッテリー電圧(2.22V付近)
   からダイオード1個分の電圧降下(0.4〜0.6V)を引いた値とほぼ一致し、**ブースト昇圧ICが
   スイッチング動作を止めて内部整流ダイオードを素通しする状態(UVLO)になった**と
   考えられる。これがLFUPSMA側の意図した保護(バッテリーを負荷から遮断する動作)なのか、
   単にICが力尽きて素通り状態になっただけで電池は依然として負荷に直結したままなのかは
   **判別できなかった**。後者の可能性を否定できなかったため、これ以上の過放電を避ける
   目的で**手動で負荷を撤去した**（§5に最初から書いていた「効かないようなら手動で
   負荷を切り離す」を実行した形）
5. **負荷撤去直後、B+/B-は2.21V→2.35V→2.36Vまで急速に回復した**。放電中の2.2V付近の
   読みのかなりの部分が、約190mA負荷時の電圧サグ（内部抵抗・分極によるもの）であり、
   真の低SOC状態でのOCVはこれより高いことを示している
6. 負荷撤去後、USBを再接続して充電を再開した。CRが点灯し、2.35V付近から2.80V・2.82Vへと
   急速に電圧が上昇中——低SOC側もLiFePO4らしい急勾配で、そのうち3.2〜3.4V帯の平坦域に
   入ると見込まれる。今回は空に近い状態からの充電なので、CR→OKへの切り替わりを
   観測できるかどうか引き続き追っている
