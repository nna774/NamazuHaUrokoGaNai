# ピエゾ実験機: 再測定で過電圧の再現性を確認、Rsを47kΩに引き上げ

## 何を決めたか

保護回路の直列抵抗Rsを**33kΩ→47kΩ**に引き上げた。想定する最悪電圧を20V→25Vへ
見直した結果。[docs/piezo.md §4](../../piezo.md#4-ピン選定と最小配線phase0)と
[docs/img/piezo-protection-circuit.svg](../../img/piezo-protection-circuit.svg)を
更新した。

## なぜ

[前回の実測](2026-08-11-piezo-overvoltage-damage.md)ではVpp 17.64V(Vmax+11.76V)
だったが、別の機会に再測定したところ**Vpp 20.74V(Vmax+10.32V/Vmin-10.44V)**を
記録した。2回の実測でどちらも十数〜二十V級の過大電圧が再現しており、単発の
異常値ではなく「ピエゾを強く弾くと確実にこの電圧域が出る」という現象として
扱うべきと判断した。

前回Rs設計時に仮定した「最悪20V」を今回の実測(20.74V)がわずかに超えたため、
想定を25Vへ引き上げて再計算した:

```
Rs = (25V - 3.6V) / 0.5mA ≈ 42.8kΩ → 標準値で47kΩ
```

Rb(10MΩ)に対してRs(47kΩ)は依然十分小さいため、信号品質への影響は無視できる。

## 何が覆ったか

- Rsを33kΩから47kΩへ変更。

## 次に何が可能になったか

- 保護回路の値が2回の実測を踏まえたものになったので、より安心して実配線に
  進められる。
