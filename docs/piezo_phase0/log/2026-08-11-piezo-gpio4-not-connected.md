# ピエゾ実験機: 「phase0達成」は誤りだった（GPIO4未接続の誤測定）

## 何を決めたか

[前回ログ](2026-08-11-piezo-phase0-first-signal.md)で「phase0達成、無入力時
pp~220-240・指で弾くとpp~700まで跳ねベースラインと明確に区別できた」と報告した
結果を**撤回する**。実際にはピエゾをGPIO4へ接続し忘れた状態での測定だった。
[docs/piezo.md §4/§5](../../piezo.md)のチェックを未達成に戻し、該当箇所に訂正を
入れた。phase0は改めて実施する必要がある。

## なぜ

配線を見直したところ、GPIO4に何も接続されていないことが分かった。フローティング
（どこにも接続されていない）ADCピンは、それ自体で不定なノイズを拾いやすい。
さらに、指を近づける/触れる動作は静電結合でフローティングピンの電位を変化させる
（いわゆる「ゴーストタッチ」現象）。前回観測した「無入力時の常時変動」と「弾いた
瞬間の跳ね上がり」は、どちらもこの現象で説明でき、ピエゾの信号だった保証が無い。

## 何が覆ったか

- [前回ログ](2026-08-11-piezo-phase0-first-signal.md)の「phase0達成」という結論を
  撤回した（ログ自体は履歴として残し、書き換えない）。
- [docs/piezo.md](../../piezo.md)のphase0チェックボックスを`[x]`から`[ ]`に戻し、
  実測結果の記述に訂正を追記した。

## 次に何が可能になったか

- GPIO4への実接続を確認した上で、改めてphase0（足音・指弾き等への反応確認）を
  やり直せる。ベースラインpp・タップ時ppの具体的な数値は、フローティングピンの
  誤測定だったため今回は参考にしない。
