# ピエゾ実験機: 保護回路の抵抗値をちゃんと計算した

## 何を決めたか

保護回路の直列抵抗Rsとバイアス抵抗Rbを、勘ではなく計算で決めた。
**Rs = 33kΩ、Rb = 10MΩ**（クランプダイオードはショットキー(BAT54等)推奨）。
[docs/piezo.md §4](../../piezo.md#4-ピン選定と最小配線phase0)の回路図・
「抵抗値の設計根拠」に反映した。

## なぜ

これまで`Rs=10kΩ`・`Rb=1MΩ前後`としていたが、どちらも具体的な計算に基づかない
仮の値だった。特にRbは、ピエゾ本体の静電容量(20-27mm級のブザー素子で概算
~20nF)とRC高域通過フィルタを作るため、値を誤ると1-10Hz帯の信号そのものを
削ってしまう。`Rb=1MΩ`だとカットオフは`1/(2π×1MΩ×20nF)≈8Hz`となり、狙いの
帯域のど真ん中に来てしまう誤りだった。カットオフを0.8Hz付近に置く設計へ
計算し直し、`Rb≈10MΩ`とした。

Rsは、[2026-08-11-piezo-overvoltage-damage.md](2026-08-11-piezo-overvoltage-damage.md)
で実測したVpp 17.64V(Vmax+11.76V)の実績を踏まえ、次にもっと強く弾いた場合の
余裕を見て最悪20Vを想定し、クランプ後の電流を0.5mA以下に抑える設計とした
（ESP32-C3のピン許容注入電流の正確な値はデータシート未確認のため、十分保守的な
値として設定）。この過程で、1N4148(順方向降下~0.7V)だとクランプ後の電圧が
ESP32の絶対最大定格(概ねVDD+0.3V≈3.6V)にほぼ余裕が無くなると気づき、
ショットキーダイオード(順方向降下~0.4V)を推奨に変更した。

回路図も、バイアス抵抗がピエゾの2端子間に直接入るという配線が前回のASCII図
だとGND-GND間のように見えて分かりにくかったため、ノードを明示する形に描き
直した。

## 何が覆ったか

- Rbを`1MΩ前後`から`10MΩ`に変更（前の値は信号帯域を削ってしまう誤りだった）。
- クランプダイオードの推奨を「1N4148等」から「ショットキー(BAT54等)推奨」に
  変更。

## 次に何が可能になったか

- ピエゾ本体の静電容量を実測できれば(仮定20nFを検算)、Rbの値をより正確に
  追い込める。
- 抵抗値が決まったので、あとは部品を揃えて配線し、GPIO4への接続とphase0に
  進められる。
